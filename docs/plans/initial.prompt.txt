This project is a monolith WebApp which to provide Mobile API, BackOffice, and the website landing page. 
Read all codebase first and read the rule below.

Backend and API provider supposed to use GoLang and the frontend of backoffice and landing page use ReactJS.

React JS and Backend Architecture and Code Pattern approach:
- Modular by feature based 
- Each feature has its own component, service, local, state, and ui management that closed from others
- For component that used by more than one feature, it suposed defined as global component
- All agentic code creation supposed documented under .agents/journal
- The react screen and component supposed to have structured code which top is the import, variable. middle is the UI output, and bottom is the styling. Another files adjust accordingly.
- Write unit test with coverage > 80%

Branching strategy:
- One work of plan prompt supposed work under specific worktree by specific branch 
- Small commit is necessary with this structure: {feature name}: {short changes description}
- Push to origin when all work done 
- Remove worktree when human said the branch been merged
