Idiomatic Go Patterns

Implements industry-standard Go design patterns and best practices for building scalable, maintainable, and efficient applications.

This skill provides Claude with expert knowledge of Go (Golang) conventions, enabling it to write code that adheres to the language's core philosophy of simplicity and clarity. It guides developers through complex architectural decisions like implementing hexagonal architecture, managing sophisticated concurrency models using errgroups and worker pools, and executing robust error handling strategies. By enforcing idiomatic practices—such as accepting interfaces while returning structs and making zero values useful—the skill ensures that Go codebases remain clean, testable, and production-grade while proactively identifying and avoiding common anti-patterns like init() side effects or goroutine leaks.
